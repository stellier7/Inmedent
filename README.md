# Inmedent

Dental practice website for **Inmedent** — Plaza Savannah, Tegucigalpa, Honduras.

Built from the [dentist-template](https://github.com/stellier7/dentist-template) static site. All practice content lives in `js/config.js`.

## Quick start

```bash
npx serve .
# or: python3 -m http.server 3000
```

Visit `http://localhost:3000`.

## Customize

1. Edit `js/config.js` for practice info, services, hours, etc.
2. Drop image assets in `assets/images/` (see `assets/images/README.md` for the checklist).

## Deploy

Push to GitHub and deploy as a static site on Vercel (see `vercel.json`).
